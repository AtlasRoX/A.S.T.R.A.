# Crew portraits

Put one square portrait per crew member here, named by crew id:

- `ana.webp`   (Cdr. Ana Ribeiro, Commander)
- `kenji.webp` (Dr. Kenji Arai, Crew Medical Officer)
- `sara.webp`  (Eng. Sara Okafor, Flight Engineer)
- `lucas.webp` (Dr. Lucas Moreau, Mission Specialist)

256x256 WebP is plenty. If a file is missing, the avatar shows the initials.

The full-size originals (AI-generated, 1254x1254 PNG) live in `astra/assets/crew-source/`, outside `public/`, so
they are not served or shipped. The WebP files here are head-and-shoulders crops of them.

Use portraits of fictional people only (AI-generated, or licensed stock with a model release).
The app shows made-up medical alerts next to these faces, so never use photos of real, identifiable people.
